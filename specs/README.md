# Specs

Project plans, specifications, architecture, investigations, and verification evidence live here.

- `product/`: purpose, scope, glossary, and snapshots.
- `tech-architecture/`: observed architecture and technical plans.
- `epics/`: implementation stories and tasks; `archive/` holds completed work.
- `adr/`: architectural decisions.
- `verifications/`: check results and review evidence.
- `bugs/`: defect investigations and registry.
- `state.yaml`: workflow mode and session handoff.

Empty scaffold files are placeholders, not approved plans or evidence of completion.
